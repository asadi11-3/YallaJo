YALLAJO ACCOUNTS MODULE - COMPREHENSIVE ANALYSIS
================================================================================

EXECUTIVE SUMMARY
================================================================================

The Accounts module manages user profiles linked to Security identities. 
Profile creation happens in TWO distinct flows:

1. SYNCHRONOUS (Auth.Register or Auth.InviteUser):
   Auth → Security.RegisterAsync() → Accounts.CreateForUserAsync() 
   (same request, immediate)

2. ASYNCHRONOUS (via UserCreatedIntegrationEvent):
   Security publishes event → OutboxProcessor → 
   Accounts.UserCreatedIntegrationEventHandler → Profile created
   (background job, eventual consistency)

CRITICAL FINDING: Both paths are SAFE and IDEMPOTENT. Profile creation 
checks for existing profiles and returns gracefully if already created.

2. APPLICATION LAYER - PROFILE CREATION (CRITICAL)
================================================================================

File: C:\Users\User\source\repos\YallaJoJo\Accounts.Application\Services\ProfileCreationService.cs

PUBLIC INTERFACE (exposed via Accounts.Contracts):
  - CreateForUserAsync(ProfileCreationRequest) → Result<Guid>
  - CreateForInvitedUserAsync(InvitedProfileCreationRequest) → Result<Guid>

IMPLEMENTATION:
  1. Checks if profile already exists (idempotency)
  2. If exists: returns Conflict error
  3. If not: creates Profile aggregate via Profile.Create()
  4. Sets optional DisplayName and AvatarUrl
  5. Adds to repository
  6. Calls SaveChangesAsync() immediately (SYNCHRONOUS)
  7. Returns profile ID

CRITICAL POINTS:
  - Synchronous: SaveChangesAsync() called immediately
  - Idempotent: Checks for existing profile before creation
  - No event publishing: Does not emit domain or integration events
  - Exposed via contract: Used by Auth module for orchestration

3. APPLICATION LAYER - GET PROFILE QUERY (CRITICAL)
================================================================================

File: C:\Users\User\source\repos\YallaJoJo\Accounts.Application\Queries\GetProfile\GetProfileQueryHandler.cs

HANDLER LOGIC:
  1. Query Accounts database for profile by UserId
  2. If profile is null: return 404 "Profile not found"
  3. Query Security module for contact data (email, phone)
  4. If contact is null: return 404 "User not found"
  5. Combine profile + contact data
  6. Return GetProfileResult

CRITICAL ISSUE:
  - Returns 404 if profile doesn't exist
  - Does NOT distinguish between:
    a) Profile never created (permanent)
    b) Profile not yet created (async event pending)
  - No retry logic
  - No "please wait" response

CACHING:
  - Cache key: accounts:profile:{userId}
  - Duration: 10 minutes
  - Tag: accounts:profile:{userId}
  - Failures are NOT cached (only successes)

4. APPLICATION LAYER - INTEGRATION EVENT HANDLERS
================================================================================

File: C:\Users\User\source\repos\YallaJoJo\Accounts.Application\EventHandlers\UserCreatedIntegrationEventHandler.cs

THIS HANDLER CREATES PROFILES ASYNCHRONOUSLY!

FLOW:
  1. Check if message already processed (inbox idempotency)
  2. If yes: log warning and return
  3. Check if profile already exists
  4. If yes: mark inbox as processed and return
  5. If no: create profile from event data (FirstName, LastName only)
  6. Add profile to repository
  7. Mark inbox message as processed
  8. Call SaveChangesAsync() (ATOMIC with profile creation)
  9. Log success

CRITICAL POINTS:
  - Creates profile with ONLY FirstName and LastName
  - Does NOT set DisplayName or AvatarUrl
  - Idempotent: checks for existing profile
  - Atomic: inbox message and profile saved together
  - No exception handling: relies on OutboxProcessor retry logic

WHEN TRIGGERED:
  - When Security publishes UserCreatedIntegrationEvent
  - Processed by OutboxProcessor in background
  - May take several seconds to minutes

  - DeleteAvatar() - clears avatar
  - UpdateName(firstName, lastName) - updates name
  - SetDisplayName(displayName) - sets optional display name
  - SetAvatarUrl(avatarUrl) - sets optional avatar URL
