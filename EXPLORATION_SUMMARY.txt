# YallaJoJo: Shared Kernel & Tests Comprehensive Exploration

## 1. SHARED KERNEL ARCHITECTURE

### 1.1 YallaJo.SharedKernel.Application - Key Interfaces

ICurrentUser (Scoped):
- Guid? UserId
- string? UserName, Email
- bool IsAuthenticated
- IEnumerable<string> Roles, Permissions
- IEnumerable<Claim> Claims
- Methods: GetClaim(), HasPermission(), IsInRole()

IRequestContext (Scoped):
- string? IpAddress, UserAgent, DeviceName, AcceptLanguage, Platform

ICommand / ICommand<TResponse>:
- ICommand : IRequest<Result>
- ICommand<TResponse> : IRequest<Result<TResponse>>

ICommandHandler / ICommandHandler<TCommand, TResponse>:
- Implements IRequestHandler<TCommand, Result>
- Implements IRequestHandler<TCommand, Result<TResponse>>

IQuery<TResponse> : IRequest<Result<TResponse>>
IQueryHandler<TQuery, TResponse> : IRequestHandler<TQuery, Result<TResponse>>

ICacheableQuery (Marker for HybridCache):
- string CacheKey { get; }
- TimeSpan? CacheDuration { get; }
- IReadOnlyList<string> Tags => []

ValidationBehavior (MediatR Pipeline):
- Runs all IValidator<TRequest> validators in parallel
- Converts failures to Result.Invalid(errors) or Result<T>.Invalid(errors)
- Logs validation failures with property names

### 1.2 YallaJo.SharedKernel.Domain - Result Types

Result (non-generic):
- bool IsSuccess, IsFailure
- Outcome Outcome
- IReadOnlyList<string> Messages
- IReadOnlyList<Error> Errors
- Factory methods: Success(), Created(), NotFound(), Unauthorized(), Forbidden(), Conflict(), ServerError(), Canceled(), Invalid(), Failure()

Result<T> (generic):
- bool IsSuccess, IsFailure
- Outcome Outcome
- T? Value
- IReadOnlyList<string> Messages
- IReadOnlyList<Error> Errors
- Error? Error => Errors.FirstOrDefault()
- Monadic operations: Map<TNew>(), Bind<TNew>()
- Side effects: OnSuccess(), OnFailure()
- Pattern matching: Match<TResult>()

Error (record):
- string Code, Message
- Factory methods: Failure(), NotFound(), Validation(), Conflict(), Unauthorized(), Forbidden()

Outcome (enum):
- Ok = 200, Created = 201, Invalid = 400, Unauthorized = 401, Forbidden = 403
- NotFound = 404, Conflict = 409, ServerError = 500, TooManyRequests = 429, Canceled = 499

### 1.3 YallaJo.SharedKernel.Presentation - ResultExtensions

ToApiResult<T>(Result<T> result):
- Success: 200 OK or 201 Created (if Outcome.Created)
- Failure: RFC 7807 Problem response

ToApiResult<T>(Result<T> result, Func<T, string> locationFactory):
- Success: 201 Created with Location header
- Failure: RFC 7807 Problem response

ToApiResult(Result result):
- Success: 200 OK
- Failure: RFC 7807 Problem response

Authorization:
- MustHavePermissionAttribute(feature, action) : AuthorizeAttribute
- PermissionAuthorizationHandler : AuthorizationHandler<PermissionRequirement>
- PermissionClaimType = "Permission"

### 1.4 YallaJo.SharedKernel.Infrastructure - DependencyInjection

Registers:
- IDomainEventDispatcher -> MediatRDomainEventDispatcher (Scoped)
- HybridCache with 15-min default expiration, 5-min local cache
- IDateTimeProvider -> DateTimeProvider (Singleton)

- SectionName = "Invite"

## 3. AUTH MODULE COMMANDS

LoginCommand(string Email, string Password) : ICommand<LoginResult>
- Normalizes email: Trim().ToLowerInvariant()
- Calls ISecurityService.VerifyCredentialsAsync() for password check
- Creates Device with UserAgent, DeviceName from IRequestContext
- Creates Session (30-day expiration)
- Generates RefreshToken (hashed in DB)
- Generates AccessToken (JWT)
- Returns: UserId, AccessToken, RefreshToken, RefreshTokenExpiresAt

LinkExternalProviderCommand(string Provider, string ProviderUserId, string? ProviderEmail) : ICommand<Guid>
- Requires authentication (ICurrentUser.IsAuthenticated)
- Dual conflict checks:
  1. User can't link same provider twice
  2. Provider ID can't be claimed by multiple users
- Normalizes provider: Trim().ToLowerInvariant()
- Returns: ExternalProvider.Id

TrustDeviceCommand(Guid DeviceId) : ICommand
- Requires authentication
- Ownership check: device.UserId == currentUser.UserId
- Idempotent: checks !device.IsTrusted before calling Trust()
- Device.Trust() sets IsTrusted=true, TrustedAt=DateTime.UtcNow

## 5. TEST STRUCTURE & CONVENTIONS

Framework: xUnit 2.9.3
Mocking: NSubstitute 5.3.0
Assertions: FluentAssertions 7.0.0
Validation: FluentValidation 12.1.1
Database: EF Core InMemory 9.0.13
Global Using: using Xunit;

Test Base Classes:
- DomainTestBase: RandomSlug(prefix)
- DomainEventAssertions: ShouldContainDomainEvent<TEvent>(entity)

Test Doubles:
- PassThroughTransactionalExecutor: ITransactionalExecutor test double
  - Runs delegate inline, no transaction enlistment
  - Tracks InvocationCount

Existing Auth Tests:
- RegisterCommandHandlerTests (142 lines): Happy path, failure propagation, email failure, email normalization
- VerifyEmailCommandHandlerTests (145 lines): Cross-module transaction testing, Security failure rollback
- OtpDomainTests (56 lines): Create defaults, attempt exhaustion, mark used, custom expiry
- UserAggregateTests (84 lines): Register event, password hash, email verification, idempotency
- ResetPasswordCommandHandlerTests, ForgotPasswordCommandHandlerTests, etc.

Test Pattern (NSubstitute):
- Substitute.For<T>() for mocks
- Arg.Any<T>(), Arg.Is<T>(predicate), Arg.Do<T>(action) for argument matching
- Received(count), DidNotReceive() for verification
- FluentAssertions: .Should().BeTrue(), .Should().Be(), .Should().ContainSingle()
- Capture pattern: Arg.Do<T>(o => captured = o)
- Async tests: async Task with CancellationToken.None
